## h3

```mermaid
%%{init: {'theme':'base','themeVariables':{'background':'#ffffff','primaryColor':'#ffffff','lineColor':'#3b6ea5','primaryTextColor':'#1a2b3c'}}}%%

flowchart TB
    START([Checker submits LC case: MT700 plus documents])
    START --> INTAKE[Case Intake UI captures files]
    INTAKE --> WFCALL[Case Workflow Service calls Harness Execute API]

    WFCALL --> READ[Harness: Read - parse LC text, segment and extract documents]
    READ --> PLAN[Harness: Plan - select Domain Agents using Governance Config]
    PLAN --> EXEC[Harness: Execute - Domain Agents run checks]
    EXEC --> RECON[Harness: Reconcile - merge findings, resolve conflicts]
    RECON --> REPORT[Harness: Report - build Checker Memo]

    REPORT --> RETURN[Findings returned to Case Workflow Service]
    RETURN --> STORE[Store findings in Case and Findings DB]
    STORE --> SHOW[Checker Memo Review UI displays result]

    SHOW --> DECISION{Checker reviews finding}
    DECISION -->|accept| CLOSE[Update case status]
    DECISION -->|override| CLOSE
    DECISION -->|flag as new case| GOVUPDATE[Submit to Compliance Console]
    GOVUPDATE --> GOVDB[(Governance Data updated)]
    GOVDB -.->|used in future cases| PLAN
```
